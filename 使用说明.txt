合约部署控制台（Windows x64 · 纯 Node 离线版）

启动条件
1. Windows 已安装 Node.js 20 或 22 x64，并可在命令行执行 node。
2. 系统已具备 Node 原生模块所需的 Microsoft VC++ 运行库。
3. 无需联网下载 npm 包；本目录已包含运行所需依赖。

启动
双击 启动控制台.cmd，浏览器会自动打开 http://127.0.0.1:4174/。
关闭命令窗口即停止本机页面服务。

使用
1. 在页面填写 RPC、Chain ID 和 Admin 钱包。
2. “上传源码存储目录”留空时，源码保存在本目录 .runtime\source-sets；也可填写 D:\ContractSources 这类 Windows 绝对路径。
3. 升级时上传目标合约和它引用的全部本地 .sol 依赖。目标合约填写代理地址，Types、接口等依赖标记为“编译依赖”。
4. 部署整套时，同样上传完整源码集，可直接选择源码目录。

说明
- 工具内不附带任何业务合约源码。
- 工具只连接页面填写的外部 RPC，不启动本地区块链。
- 包内没有 EXE 文件，不执行 npm install，也不下载 Solidity 编译器。
- Hardhat 运行所需的 Windows .node 原生模块必须保留。
- 业务记录写入 data\records，OpenZeppelin 网络记录写入 .openzeppelin；使用后请一起备份。
- 换电脑后，自定义目录中的旧源码索引可能失效，重新上传源码即可。
